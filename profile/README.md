## Sobre la asignatura

Esta asignatura introduce la programación con **Python** a estudiantes del Grado en Matemáticas asumiendo que parten de cero. El énfasis está en la lógica matemática y el razonamiento algorítmico, no en la configuración de entornos.

Para eliminar la fricción inicial, todo el trabajo se realiza en **GitHub Codespaces**: un entorno de desarrollo completo que corre en el navegador, sin necesidad de instalar nada en el ordenador personal.

## Estructura del curso

El curso se desarrolla a lo largo de 15 semanas (60 horas presenciales) organizadas en 9 temas:

| # | Tema | Horas |
|---|------|:-----:|
| 1 | Fundamentos, Entornos Modernos y Asistentes IA | 4 h |
| 2 | Componentes del Lenguaje y Control de Flujo | 8 h |
| 3 | Funciones, Módulos y Organización del Código | 4 h |
| 4 | Estructuras de Datos nativas fundamentales de Python | 8 h | 
| 5 | Algoritmos Básicos y Verificación | 8 h |
| 6 | Programación Orientada a Objetos | 8 h |
| 7 | Gestión de Datos y Ficheros | 4 h |
| 8 | Ecosistema Científico de Python | 12 h |
| 9 | Diseño Algorítmico y Resolución de Problemas | 4 h |

## Cómo empezar

1. **Crea una cuenta en GitHub** si aún no tienes una — es gratuita y la usarás durante toda la carrera.
2. **Accede al sitio web del curso** para consultar los contenidos, ejercicios y recursos:
   👉 [uib-23200-programacion.github.io/website](https://uib-23200-programacion.github.io/website/)
3. **Abre el repositorio de ejercicios** del tema correspondiente y sigue las instrucciones del `README.md` para lanzar un Codespace con un solo clic.

> No necesitas instalar Python ni ningún editor en tu ordenador. Todo funciona desde el navegador.

## Tecnología utilizada

| Herramienta | Uso |
|-------------|-----|
| **Python 3.13** | Lenguaje del curso |
| **GitHub Codespaces** | Entorno de desarrollo en la nube |
| **Dev Containers** | Configuración reproducible del entorno |
| **Marimo** | Notebooks interactivos para los ejercicios |
| **Quarto** | Sitio web del curso (bilingüe ES/CA) |
| **GitHub Actions** | Integración continua y evaluación automática |

## Repositorios de ejercicios

Los repositorios de ejercicios siguen la convención de nombres `tXX-nombre-del-tema` y están disponibles para los estudiantes matriculados. Cada repositorio incluye:

- Un `devcontainer.json` con el entorno preconfigurado
- Los notebooks de Marimo con los enunciados
- Un `pyproject.toml` con las dependencias del tema
- Un workflow de GitHub Actions para la validación automática
